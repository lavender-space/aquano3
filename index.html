ПРОЗРАЧНЫЙ РАСЧЁТ

Как это работает.

Цвет — измеряемый сигнал. Калибровка связывает его с концентрацией.

От фотографии к числу

  1. Используйте тест-полоску по инструкции производителя. Снимайте её через то же время реакции, что и при калибровке.
  2. Сохраните устройство, освещение, расстояние и настройки камеры. Избегайте фильтров, теней, бликов и пересвеченных областей.
  3. Загрузите исходное фото. Выделите внутреннюю часть именно нитратного поля. Приложение усреднит RGB всех непрозрачных пикселей области без уменьшения фотографии.
  4. Выберите соответствующий профиль. Для нового смартфона или партии полосок постройте собственную калибровку.
y = G / (R + G + B)
y = a + b · C
C = (y − a) / b

Здесь C — концентрация нитрат-иона NO₃⁻ в мг/дм³ (то же, что мг/л), а не концентрация соли или азота нитратов. RGB — средние значения каналов изображения от 0 до 255; нормирование выполняется после усреднения.

Собственная калибровка

Введите значения для стандартных растворов с известной концентрацией по NO₃⁻. Приложение строит линейную регрессию методом наименьших квадратов: C — независимая переменная, Gнорм — зависимая. Обратная формула используется только внутри фактического диапазона стандартов, ограниченного 0–100 мг/дм³.

Рецептура приготовления растворов в приложение не включена: используйте утверждённую методику исследовательской работы и работу под руководством преподавателя.

Как читать результат

Внутри рабочего диапазона

Отображается ориентировочная концентрация с одним десятичным знаком. Это формат отображения, а не заявленная точность измерения.

Область очень низких концентраций

Если обратный расчёт для профиля с нижней границей 0 даёт нулевое или отрицательное значение, точное число не показывается. Это не доказательство отсутствия нитратов. Предел обнаружения и количественного определения не установлен.

За границами калибровки

Выше 100 мг/дм³ численный результат не выдаётся. У своего профиля верхняя граница может быть ниже 100, а нижняя — выше 0. В этом случае действуют границы именно этого профиля. Формула за границей используется только для определения стороны выхода, без точной экстраполяции.

ⓘ

Метод не устанавливает безопасность воды. Даже результат внутри калибровки не заменяет лабораторный анализ. Приложение не сравнивает измерение с нормативом питьевой воды.

Данные на вашем устройстве

Фотографии не отправляются на сервер. Профили и точки черновика хранятся в браузере. Очистка данных браузера удалит их. Скачанные результаты содержат RGB и формулу, но не фотографию.
