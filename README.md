# AquaNO₃

Исследовательское веб-приложение для цифровой экспресс-оценки нитратов в воде.

## Возможности

- Анализ фотографии тест-полоски: ручное выделение нитратного поля, средние RGB, нормированный G/(R+G+B).
- Два исходных калибровочных профиля и собственные профили по стандартным растворам.
- Линейная регрессия, R², график, локальное сохранение и импорт/экспорт профилей.
- Ограничение диапазоном калибровки и предупреждение об экспресс-скрининге.
- Адаптивный интерфейс для компьютера и телефона.

Фотографии обрабатываются только в браузере и не отправляются на сервер. Приложение не устанавливает безопасность воды и не заменяет лабораторный анализ.

## GitHub Pages

Это готовая папка сайта. Зависимости, сборка и отдельный сервер не требуются.

Для публикации используется публичный репозиторий `aquano3` и источник Pages `main` / `/ (root)`. Главный файл `index.html` находится в корне. Файл `.nojekyll` отключает ненужную обработку статических файлов.

Все адреса ресурсов относительные: приложение подходит для адреса вида `https://ИМЯ.github.io/aquano3/`.

QR-коды `qr.png` и `qr.svg` подготовлены для адреса `https://lavender-space.github.io/aquano3/`. При смене владельца или названия репозитория коды нужно обновить.

## Профили при переносе

Локальные профили сохраняются отдельно для каждого адреса сайта и браузера. Чтобы перенести свою калибровку со старой версии, экспортируйте профиль в JSON и импортируйте его на новом сайте.

## Исходные калибровки

Основной смартфон: y = 0.332148 − 0.000832 C, R² = 0.9812.

Второй смартфон: y = 0.353782 − 0.000957 C, R² = 0.9784.

C выражается в мг/дм³ по нитрат-иону NO₃⁻; y = G/(R+G+B). Исходный диапазон — 0–100 мг/дм³. Числа за границами профиля не экстраполируются в точную оценку.

## Оформление

Обновлённый дизайн использует бирюзовые, голубые и сиреневые акценты. Декоративные изображения воды и лабораторного стекла в `assets/` созданы с помощью ImageGen; они не являются фотографиями эксперимента или результатами измерений. Изображения сжаты в WebP и хранятся вместе с сайтом, без внешних фотосервисов и шрифтов.
